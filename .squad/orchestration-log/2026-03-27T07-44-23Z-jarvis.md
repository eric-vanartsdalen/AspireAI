### "Legacy Schema" Concept
- No separate legacy path detection; "legacy" refers to schema shape, not location
- Schema incompatibility detected by missing required columns from `files` table
- Self-healing via `_ensure_required_columns()` adds missing columns at startup

## Decision Rationale

`test_legacy_schema_startup_failure_reports_path_and_cause` validates edge case diagnostics when self-healing is unavailable. The test:
1. Creates intentionally incomplete schema (missing `file_hash` and others)
2. Patches `_ensure_required_columns()` to disable self-healing
3. Simulates scenario where self-healing cannot run
4. Verifies error message includes path, "no such column", diagnostics, schema label
5. Validates diagnostic quality when startup fails

Production code self-heals normally; test validates fallback diagnostics when self-healing is unavailable—both paths remain important.
