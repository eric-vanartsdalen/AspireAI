## Notes for Successors

- **Test Maintenance Pattern:** When cross-service contracts change (DB names, connection strings, environment variables), update test expectations to **derive** the contract from source (AppHost for centralized config) rather than hardcoding literal values.

- **Regression Test Sensitivity:** Tests should catch real contract drift (e.g., AppHost using `different-db` while Web/Python still use `appdb`), but must be resilient to intentional renames by deriving values dynamically.
